# [P1] ระบุประเภทความสัมพันธ์และผลลัพธ์ของกรณีศึกษากับ framework

## ปัญหา

หัวข้อ "เคยถูกใช้แก้ปัญหาจริงที่ไหนบ้าง" รวมการใช้โดยตรง การดัดแปลง การตีความย้อนหลัง แนวคิดใกล้เคียง ที่มาของแนวคิด และกรณีเตือนใจไว้ด้วยกัน ความต่างบางอย่างอยู่ใน note ซึ่งปัจจุบันมักถูกซ่อน ผู้อ่านจึงอาจเข้าใจว่าทุกองค์กรใช้ framework นั้นจริง

## ตัวอย่างจาก data/use-cases.json

- Rubber Band Model: Priestley/Franklin และ Darwin เป็นรายการชั่งข้อดีข้อเสีย; note ระบุว่าไม่ใช่โมเดลนี้โดยตรง
- RACI: Apple/GitLab ใช้ DRI; European Commission ใช้ RASCI; ความสัมพันธ์ต่างจาก RACI เต็มรูปแบบ
- RICE: GrowthHackers ใช้ ICE ซึ่งเป็นคนละสูตร
- SMART: Apollo/Kennedy เป็นการตีความย้อนหลังและติด disputed
- Cynefin: งานวิเคราะห์เดนมาร์กช่วง COVID เป็นการใช้กรอบวิเคราะห์ย้อนหลังโดยนักวิจัย
- VSM: บางตัวเลขคือศักยภาพจากแผนที่อนาคต ไม่ใช่ผลหลังใช้งาน

## งานที่ต้องทำ

- ออกแบบ field แบบเลือกค่าที่ระบุความสัมพันธ์กับ framework เช่น direct/adapted/retrospective/related/origin/counterexample พร้อม label ภาษาไทย
- แยกมิติผลลัพธ์/คุณภาพหลักฐาน เช่น measured/self-reported/projected/adoption-only/no-outcome ออกจากความสัมพันธ์; ไม่ใช้ disputed แทนทุกมิติ
- ตรวจและจัดประเภททั้ง 326 กรณีจากข้อมูลและหลักฐานที่มี; ถ้ายืนยันไม่ได้ให้ระบุความไม่แน่นอน ไม่เดา
- แสดงประเภทและข้อจำกัดบน desktop/mobile และส่งให้ WebMCP/AI ด้วย
- หัวข้อรวมต้องครอบคลุมประเภทกรณีจริงโดยไม่อ้างว่าทุกเคสเป็นการใช้โดยตรง
