# [P1] ตรวจตัวเลขที่ขัดกันและเพิ่มเงื่อนไขให้คำแนะนำ framework

## ปัญหา

พบข้อความขัดกันภายในและคำแนะนำที่เขียนเป็นกฎตายตัวในเนื้อหา การตรวจนี้ยืนยันสิ่งที่อยู่ใน repo ได้ แต่ยังไม่ได้เปิดตรวจแหล่งอ้างอิงภายนอกครบ 368 URL จึงต้องตรวจต้นทางก่อนแก้ข้อกล่าวอ้าง

## งานที่ต้องทำ

- ตรวจจุดข้างต้นกับแหล่งปฐมภูมิที่เปิดอ่านได้ แก้ทั้งข้อความและ diagram.spec เมื่อมีข้อมูลซ้ำกัน
- ตรวจทั้ง 61 framework เพื่อแยกหลักการ ข้อเสนอเริ่มต้น และเงื่อนไขการใช้ โดยรักษาเนื้อหาให้กระชับ
- ผลลัพธ์องค์กรต้องไม่สรุปว่า framework เป็นสาเหตุเดียวเมื่อใช้หลายมาตรการร่วมกัน
- เขียนใหม่ด้วยภาษาของโครงการ เก็บเครดิตและ URL; ไม่คัดภาพ/ตาราง/ข้อความยาวจากหนังสือ
