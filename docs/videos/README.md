# คลิปอธิบาย framework

ทุก framework ที่มีคลิปจะมี **2 ขนาดจากเรื่องเดียวกัน**: 16:9 สำหรับหน้าเว็บ desktop และ 9:16 สำหรับแอปมือถือ คลิปทุกตัวจะถูกนำไปโพสต์ต่อบน Facebook, Instagram และ TikTok พร้อมลิงก์กลับมาหน้าเว็บด้วย

โทนของคลิปคือ **สนุก ตื่นเต้น ชวนค้นหา** ตัวอย่างในคลิปเป็นเรื่องสมมติจากธุรกิจที่คนทั่วไปเข้าใจง่าย เช่น ร้านอาหาร โรงแรม ฟาร์ม หรือร้านค้า และไม่ใช้ตัวอย่างงานทีมข้อมูลที่อยู่ในหน้าเว็บ ตอนจบต้องชวนคนดูไปต่อที่ framework ตัวถัดไป

```text
data/frameworks.json ──► npm run video:brief ──► brief.json · brief.md · diagram.svg
                                                        │
              บทพากย์แยกฉาก ──► ElevenLabs: เสียงพากย์ · เพลง · เสียงประกอบ
                                                        │  ความยาวเสียงกำหนดความยาวฉาก
              claude-motion-clip (ในเครื่อง): โฟลเดอร์คลิป 9:16 + 16:9
                                                        │
                 เรนเดอร์ทีละเฟรม ──► ผสมเสียง ──► WebM (เว็บ) + MP4 (โซเชียล)
                                                        │
          public/videos/ ──► npm run video:add (2 ขนาด) ──► หน้าเว็บ · แอปมือถือ · WebMCP
```

## เครื่องมือ

| | เครื่องมือ | หมายเหตุ |
| --- | --- | --- |
| ภาพ | skill `claude-motion-clip` ในเครื่อง (`~/.ai_skills/video/claude-motion-clip`) | ฉากเป็น HTML/CSS ที่คำนวณจากเวลา `t` แล้วให้ Chrome ในเครื่องถ่ายทีละเฟรม การ์ดผูกกับคำที่พูดด้วย `w:<คำ>` ต้นฉบับเก็บใน git ที่ `clips/<slug>/<ชุด>/` (ฉาก เสียงพากย์ที่เลือก เพลง เสียงประกอบ) มีโฟลเดอร์ `desktop/` กับ `mobile/` ที่ใช้โค้ดฉากชุดเดียวกัน ดู [clips/README.md](../../clips/README.md) **ห้ามสร้าง artifact บน claude.ai** (คลิป 5 Whys ชุดแรกเคยทำเป็นฟิล์ม Motion บน claude.ai ก่อนจะตกลงกันเรื่องนี้) |
| เสียง | ElevenLabs | เสียงพากย์ `eleven_v4` ใช้เสียงไทยจาก Voice Library ส่วนเพลงประกอบ (`eleven_music`) และเสียงประกอบ (`eleven_text_to_sound`) ก็มาจาก ElevenLabs เช่นกัน ภาษาไทยต้องใช้รุ่น v3/v4 |
| ตรวจการออกเสียง | Whisper ในเครื่อง (`words.sh` ของ skill) | วัด CER ของแต่ละ take เทียบกับบท ส่วนที่ผิดเพราะชื่ออังกฤษหรือตัวเลขไม่ถือว่าเสียงผิด Whisper จับพยัญชนะควบที่หายไม่ได้ (เคยได้ยิน "กรอบ" เป็น "รอบ" แต่ผ่าน) ชื่อเว็บและชื่อเฉพาะต้องให้เจ้าของฟังเอง |

## ทำคลิปหนึ่งตัว

1. **สร้าง brief**: รัน `npm run video:brief -- <slug>` ได้ไฟล์ใน `.cache/video-briefs/<slug>/` (ไม่เข้า git) ไฟล์ `brief.json` มีฉาก กติกา และสเปกที่ต้องส่ง
2. **เขียนบทพากย์แยกฉาก**: ข้อเท็จจริงของ framework ต้องมาจาก brief เท่านั้น ส่วนตัวอย่างให้แต่งใหม่จากธุรกิจที่คนเข้าใจง่าย บทใส่แท็กอารมณ์ภาษาอังกฤษ เช่น `[excited]` ได้ ชื่ออังกฤษให้เขียนตามเสียงอ่าน เช่น "ไฟว์วายส์"
3. **ทำเสียงก่อนภาพ**: สร้างเสียงพากย์ทีละฉาก ฉากละ 2 take แล้วเลือก take ที่ CER ต่ำที่สุด
   - ใช้ Whisper (`check_takes.py --words`) หาเวลาของแต่ละคำ
   - ความยาวฉากเท่ากับความยาวเสียงบวกช่วงเงียบหัวท้าย ปัดเป็นจำนวนเฟรมเต็มที่ 30fps เพื่อไม่ให้ภาพกับเสียงเลื่อนกัน
4. **ทำภาพในเครื่องด้วย `claude-motion-clip`**: วางต้นฉบับที่ `clips/<slug>/<ชุด>/` ตามโครงสร้างใน [clips/README.md](../../clips/README.md) ขนาด 1080×1920 (`mobile/`) และ 1920×1080 (`desktop/`) ใช้ไฟล์ฉากชุดเดียวกัน
   - ข้อความบนจอขึ้นตามคำพูดและใช้แทนซับ
   - วางข้อความเรียงต่อกันตามความสูงจริง ไม่ใช้พิกัดตายตัว จะได้ไม่ทับกัน
   - ฉบับแนวตั้งต้องเว้นข้อความให้ห่างขอบบน 250 ขอบล่าง 420 และขอบขวา 120 px เพราะแอปโซเชียลวางปุ่มทับตรงนั้น
   - ฉากตัวอย่างมีป้าย "ตัวอย่างสมมติ" ตลอดฉาก
   - ตอนจบมีชื่อเว็บ ชวนไปดู framework ตัวถัดไป และบอกว่าคลิปสร้างด้วยเครื่องมือ AI
5. **ตรวจภาพนิ่ง**: รัน `check.js` ของ skill แล้วเปิด `check/sheet-*.png` ดูว่าไม่มีอะไรทับกันและไม่ล้นขอบ ฟอนต์ IBM Plex Sans Thai ของเว็บอยู่ในโฟลเดอร์ `fonts/` ของคลิป
6. **เรนเดอร์และผสมเสียง**: เรนเดอร์ครบทุกเฟรม แล้วผสมเสียงพากย์ เพลง และเสียงประกอบตามเวลาของแต่ละฉาก
   - เพลงลดเสียงลงเองตอนมีคนพูด
   - ความดังประมาณ -14 LUFS
   - ถอดเสียงที่ผสมแล้วด้วย Whisper อีกรอบ เพื่อยืนยันว่าเสียงพากย์ยังชัด
7. **เข้ารหัส**:
   - สำหรับเว็บ: `<slug>.webm` + `<slug>-mobile.webm` (VP9 + Opus) และภาพปก `<slug>.webp` + `<slug>-mobile.webp` วางใน `public/videos/`
   - สำหรับโซเชียล: MP4 (H.264 + AAC) ทั้ง 2 ขนาด เก็บไว้นอก git
8. **เจ้าของตรวจ** ก่อนเผยแพร่:
   - เนื้อหาไม่เกินจาก brief
   - ไม่มีโลโก้หรือบุคคลจริง
   - ฟังคำที่ Whisper ทักไว้ด้วยหูอีกครั้ง
9. **ลงทะเบียนทีละขนาด**:

   ```bash
   npm run video:add -- 5-whys --size desktop --file videos/5-whys.webm --poster videos/5-whys.webp \
     --duration 1:10 --tool "Claude Motion + ElevenLabs" --title "5 Whys: ถามทำไม 5 ชั้น จนเจอราก" --hash <briefHash>
   npm run video:add -- 5-whys --size mobile --file videos/5-whys-mobile.webm --poster videos/5-whys-mobile.webp \
     --duration 1:10 --tool "Claude Motion + ElevenLabs" --title "5 Whys: ถามทำไม 5 ชั้น จนเจอราก" --hash <briefHash>
   ```

   ถ้าเสียงและภาพไม่ได้สร้างด้วย AI ให้ใส่ `--no-ai`
10. **ส่งขึ้นเว็บ**: รัน `npm test` → เพิ่มรายการใน `data/changelog.json` → เปิด PR เข้า `dev` → ตรวจบน `/dev/` → promote
11. **โพสต์โซเชียล**: ใช้ไฟล์ MP4 แนวตั้งสำหรับ Reels และ TikTok ส่วนแนวนอนใช้กับโพสต์ Facebook ปกติได้
    - ใส่ลิงก์กลับไปหน้า framework พร้อม `?utm_source=facebook|instagram|tiktok&utm_medium=social&utm_campaign=clip-<slug>`
    - Instagram และ TikTok กดลิงก์ในแคปชันไม่ได้ ให้ใส่ลิงก์ไว้ในโปรไฟล์ (bio)

## ข้อมูลใน `data/videos.json`

```jsonc
{
  "5-whys": {
    "lang": "th",
    "desktop": {                                   // 16:9 หน้าเว็บ
      "title": "5 Whys: ถามทำไม 5 ชั้น จนเจอราก",
      "durationSec": 70,
      "aspect": "16:9",
      "source": { "kind": "file", "src": "videos/5-whys.webm" }, // ไฟล์ใน public/ (ไม่มี / นำหน้า), https URL หรือ { "kind": "youtube", "id": "…" }
      "poster": "videos/5-whys.webp"
    },
    "mobile": { "…": "เหมือนกัน แต่ aspect เป็น 9:16 และใช้ไฟล์ -mobile" },
    "madeWith": { "tool": "Claude Motion + ElevenLabs", "date": "2026-11-15", "ai": true },
    "briefHash": "6989e68ffe67",
    "note": "…"                                    // ไม่บังคับ แสดงใต้คลิป
  }
}
```

`npm test` ตรวจทุกรายการผ่าน `videoProblems` ใน `scripts/video-lib.mjs`:

- ต้องมีครบทั้ง `desktop` (16:9) และ `mobile` (9:16)
- ไฟล์ใน repo ต้องอยู่ใน `public/videos/` มีอยู่จริง และไม่เกิน 20 MB ต่อไฟล์
- ไฟล์ภายนอกต้องเป็น https
- ความยาว 10–600 วินาที
- ต้องบอกว่าใช้ AI หรือไม่
- ไม่มี field ที่สะกดผิด

## คลิปที่เนื้อหาเปลี่ยนไปแล้ว

`briefHash` คือลายนิ้วมือของเนื้อหา framework ที่คลิปเล่า ได้แก่ ชื่อ ช่วงที่ควรใช้ วิธีคิด 5 ขั้นตอน ตัวอย่าง ที่มา และแผนภาพ

ถ้าแก้เนื้อหาเหล่านี้หลังทำคลิปไปแล้ว `npm run video:check` จะขึ้น `!` บอกว่าคลิปไหนควรทบทวน แต่ test ไม่ fail

## หน้าเว็บแสดงคลิปอย่างไร

- หน้า framework บน desktop เล่นขนาด 16:9 เป็นส่วนแรกก่อนแผนภาพ ส่วนแอปมือถือเล่นขนาด 9:16 ใต้หัวเรื่องก่อนแท็บ
- ก่อนกดเล่นจะโหลดแค่ภาพปก กดแล้วจึงโหลดคลิป
- ใต้คลิปบอกความยาว และบอกว่าสร้างด้วยเครื่องมือ AI ถ้า `madeWith.ai` เป็น true
- การ์ดในหน้า Frameworks และรายการในแอปมือถือมีป้าย "▶ มีคลิป m:ss"
- WebMCP `get_framework` คืน `video` ที่มี title, durationSec, url, mobileUrl และ aiGenerated
- framework ที่ยังไม่มีคลิป หน้าเว็บเหมือนเดิมทุกอย่าง

## เก็บไฟล์คลิปที่ไหน

เจ้าของเลือก (14 พ.ย. 2026) ให้เก็บคลิปใน repo ที่ `public/videos/` เป็น WebM (VP9 + Opus) เพราะเล็กกว่า MP4 ที่คุณภาพเท่ากัน และหน้าเว็บโหลดจากเว็บเดียวกันได้เลย

- **ไม่เก็บซ้ำในชุดเปรียบเทียบ**: workflow build เว็บ 7 ชุด แต่ `/v0`–`/v3` ลบ `public/videos` ก่อน build แล้วใช้ไฟล์ของชุดหลักผ่าน `assetBase` (แบบเดียวกับโมเดลค้นหา) จึงมีสำเนาแค่ใน prd, `/stg/` และ `/dev/` ส่วน GitHub Pages จำกัดขนาดเว็บไว้ 1 GB
- **เพดาน 20 MB ต่อไฟล์**: test บังคับ GitHub จะเตือนที่ 50 MB และไม่รับไฟล์เกิน 100 MB
- **ประวัติ git โตทุกครั้งที่แทนไฟล์**: ควรแทนคลิปเฉพาะตอนจำเป็นจริง
- **ขึ้นเว็บเฉพาะ WebM และต้องมี 2 ขนาดเสมอ** (เจ้าของย้ำ 21 พ.ย. 2026): WebM เล็กกว่ามาก คลิป 5 Whys ชุดแฟ้มคดียาว 58 วินาที เป็น WebM 4.0/4.4 MB ส่วน MP4 8.6/9.2 MB ห้ามขึ้นเว็บแค่ขนาดเดียว ให้ commit แยกขนาดละ commit จะได้ถอยทีละขนาดได้
- **MP4 สำหรับโซเชียลไม่เข้า git**: อยู่ใน `out/` ของโฟลเดอร์คลิป ซึ่ง `.gitignore` กันไว้ ถ้าหายก็ render ใหม่จาก `clips/` ได้
- **ต้นฉบับคลิปอยู่ใน git ที่ `clips/`**: โค้ดฉาก บท เสียงพากย์ที่เลือกแล้ว เพลง และเสียงประกอบ ราว 7 MB ต่อชุด render ใหม่ได้โดยไม่เสียเครดิต ElevenLabs ซ้ำ ห้ามมี API key หรือ token เพราะ repo เป็น public
- `.git/info/exclude` ในเครื่องเจ้าของกันโฟลเดอร์ชื่อ `videos/` ทุกที่ ตอนเพิ่มไฟล์คลิปจึงต้องใช้ `git add -f`

## ข้อจำกัดที่รู้แล้ว

- WebM เล่นได้ใน Chrome, Edge, Firefox และ Android ส่วน Safari และ iPhone รุ่นเก่าบางรุ่นอาจเล่นไม่ได้ ยังไม่ได้ทดสอบบนอุปกรณ์จริง
- คลิปแนวตั้งเว้นพื้นที่ด้านล่างไว้ให้ปุ่มของแอปโซเชียล บนหน้าเว็บจึงเห็นด้านล่างว่าง
- ยังไม่มีบทย่อย (chapters) และยังไม่มี structured data แบบ VideoObject
